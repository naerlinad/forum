# Forum Backend API

Легковесный REST API бэкенд для форума, написанный на Node.js с использованием SQLite.

## 🛠 Стек технологий
- **Node.js** + **Express** (веб-фреймворк)
- **SQLite3** (база данных, не требует отдельного сервера)
- **JWT** + **bcrypt** (аутентификация и хеширование паролей)
- **dotenv**, **cors**

## ✨ Основные возможности
- Регистрация и авторизация пользователей (JWT).
- Ролевая модель: `root` (создатель), `moder` (модератор), `user` (пользователь).
- CRUD операции для тем (threads) и постов (posts) с пагинацией.
- Управление профилем (обновление данных, удаление).
- Модерация: временный бан (`status: 'banned'`) и изменение ролей.

## 🚀 Быстрый старт

1. Клонируйте репозиторий и перейдите в папку:
```bash
   git clone git@github.com:naerlinad/forum.git
   cd forum
```

2. Установите зависимости:
```bash
   npm install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
   cp .env.example .env
```
   *Обязательно задайте свой `JWT_SECRET` в этом файле.*

4. Запустите сервер:
```bash
   node server.js
```
   Сервер автоматически создаст файл `database.sqlite` и таблицу с пользователем `root` (пароль по умолчанию: `changeme`, если не изменён в `.env`).

## ⚙️ Переменные окружения (.env)
```env
PORT=3000
JWT_SECRET=your_super_secret_key_here
ROOT_USERNAME=root
ROOT_PASSWORD=changeme
```

## 📌 Основные эндпоинты
| Метод | Маршрут | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/auth/register` | Регистрация нового пользователя | Публичный |
| `POST` | `/auth/login` | Вход и получение JWT токена | Публичный |
| `GET` | `/threads` | Список тем (с пагинацией) | Публичный |
| `POST` | `/threads` | Создание новой темы | Авторизован |
| `GET` | `/posts?thread_id=1`| Список постов в теме | Публичный |
| `POST` | `/posts` | Создание поста | Авторизован |
| `PUT` | `/users/:id` | Обновление своего профиля | Владелец / Root |
| `PUT` | `/users/moderate/:id`| Бан/разбан пользователя | Moder / Root |
| `PUT` | `/users/setrole/:id` | Изменение роли пользователя | Только Root |

*Для авторизованных запросов добавляйте заголовок:* `Authorization: Bearer <ваш_токен>`
